# 🚀 Personal Portfolio Website

A modern, interactive, and responsive personal portfolio website built to showcase my skills, projects, and experience as a Frontend Developer.

## 🌐 About The Project

This portfolio website represents my journey as a developer. It highlights my technical skills, featured projects, and contact information through a clean and modern user interface.

The website features smooth scrolling, interactive elements, and a custom cursor experience to make browsing more engaging.

## ✨ Features

- Modern and clean UI design
- Responsive layout
- Interactive custom cursor
- Smooth scrolling navigation
- About Me section
- Skills and technologies showcase
- Featured projects section
- Project details interaction
- Contact section
- Custom scrollbar
- Animated infinite marquee

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- CSS3
- JavaScript
- Lucide Icons

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/yousufali2525/interactive-portfolio.git
```

### 2. Navigate to the Project Folder

```bash
cd interactive-portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL shown in your terminal to view the website.
